Search Engine Built From First Principles

Engineering an Industrial Search Engine in Java 21

SearchForge is a custom search engine implementing every core algorithm from scratch: multi-worker polite web crawling, Unicode linguistic normalization, Porter morphological stemming, dual-tier positional inverted indexing, recursive-descent Boolean query AST evaluation, Okapi BM25 probabilistic relevance ranking, Phase 5 Query Intelligence (Trie autocomplete, Damerau-Levenshtein spelling correction, dynamic highlighted snippets, and synonym expansion), Phase 6 Frontend Web Application (React 18, Vite 6, live BM25 score transparency, multi-mode retrieval), and Phase 7 Hybrid Search & Dense Semantic Retrieval (Local ONNX Runtime inference with all-MiniLM-L6-v2, authentic 30,522-token WordPiece tokenizer, dynamic sequence length tensors, and Reciprocal Rank Fusion [RRF]).

GET /api/v1/search/semantic Direct dense semantic vector retrieval via ONNX embeddings q, limit=10

POST /api/v1/index/build Batch index unindexed crawled pages batchSize=100
POST /api/v1/index/rebuild Full index purge and rebuild from scratch none
GET /api/v1/index/stats Corpus metrics (N, V, postings, L_avg) none
POST /api/v1/crawler/start Start background crawl in Virtual Thread JSON: {"seedUrls": [...]}

Local Execution

Quickstart Guide

Launch the search engine locally in under 60 seconds.

Option A: Zero-Docker Instant Dev Runner (Recommended)

Uses an in-memory PostgreSQL-compatible H2 database with 24 multi-domain encyclopedia documents auto-seeded on startup.

cd backend
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=dev"

Option B: Full-Stack Web App (Backend + React Frontend)

Launch both the Java 21 Spring Boot search engine and the interactive Vite 6 React SERP UI.

# Terminal 1: Backend (Port 8080)
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=dev"

# Terminal 2: Frontend (Port 5173)
cd frontend
npm run dev

Option C: Persistent PostgreSQL 16 Docker Mode

# 1. Start PostgreSQL 16 Container
docker compose up -d

# 2. Run backend
cd backend
.\mvnw.cmd spring-boot:run

Option D: Run All 421 Automated Tests (408 Backend + 13 Frontend)

# Run 408 Backend Tests
cd backend
.\mvnw.cmd test

# Run 13 Frontend Tests
cd ../frontend
npm test
