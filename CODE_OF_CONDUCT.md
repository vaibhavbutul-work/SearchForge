# Community Code of Conduct

SearchForge is committed to providing a welcoming, constructive, and respectful environment for all contributors and learners.

## Guidelines

- **Respect:** Treat all collaborators with dignity, empathy, and professional respect.
- **Constructive Communication:** Provide helpful, technical feedback focused on code quality and engineering learning.
- **Collaboration:** Encourage open discussion on search algorithms, data structures, and information retrieval.

## Reporting

Issues violating community standards may be reported privately to the project maintainers.
